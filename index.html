팩트 점수 (Fact / Lie)

아래 조건을 모두 만족하는 증거 기반 투표만 Fact 또는 Lie로 집계됩니다.

  1. C1 출처 URL 또는 업로드 파일이 있음
  2. C2 자료가 커뮤니티에서 신뢰 추천 ≥ 3
  3. C3 동일 방향 적격 증거 ≥ 2건 (서로 다른 출처)
  4. C4 반대 방향 적격 증거가 더 많지 않음
Fact = 적격 True 증거 가중치 ÷ (True+False 적격 가중치)
